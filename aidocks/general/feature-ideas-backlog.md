## Internet Archive only (no Apple requests)
- **Find App ID** (Download page; POTENTIAL idea, added 2026-10-13 at the user's request: "Ad it as a patenchel idea" - not approved for building): type an app's name, the GUI turns it into the store URL slug (lowercase, dashes) and searches the Wayback Machine CDX (web.archive.org/cdx/search/cdx?url=apps.apple.com/us/app/<slug>&matchType=prefix, then itunes.apple.com/us/app/<slug>), pulls id\d+ from the results, shows the matches (name from the slug + App ID) in a list with first-letter nav ([[lists-first-letter-nav]]), and fills the App ID field. Never contacts Apple ([[protect-apple-account]]). Limits to explain: slug mismatches for long/renamed names, CDX 503/504 timeouts (retry, both hosts), apps never archived (Virtual Balloon). Credibility discussion 2026-10-13: Wayback = credible (unchanged copies of real pages), but add a VERIFY step: open the archived store page and show its name + developer (+ price/version) before filling the ID, because one slug can match different apps (e.g. "sixthsense" also matched id421794646 and matsumoto yuuki's app). Source order: archived Apple store pages (apps./itunes.apple.com) first; third-party listings (AppShopper appshopper.com/<category>/<slug> uses the iTunes ID in screenshot URLs - found Virtual Balloon 346157113; AppAdvice) as fallback; never archive.org user uploads. Keep it optional/manual (one search per click), handle CDX 503/504.
