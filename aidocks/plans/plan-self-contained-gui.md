## Goal
`ipatool-gui.exe` works on its own: the user can delete `ipatool.exe` and keep only the GUI. Two-exe option stays (the CLI is still buildable from the repo root), but the GUI no longer needs it. Bonus: real download percentage (announceable by NVDA) and clean cancel via context.

## Design
- **No copying.** `gui/go.mod` adds `require github.com/majd/ipatool/v2 v2.0.0` and `replace github.com/majd/ipatool/v2 => ../`, so Go compiles `../pkg/...` in place. Changes in pkg/ are picked up on the next GUI build.
- **cmd/ stays untouched** and is still used only by the CLI (`main.go` -> `cmd.Execute()`). Its setup helpers are unexported (`newKeychain`, `newCookieJar`, `prepareStateDirectory`, `initWithCommand` in cmd/common.go and cmd/state_directory.go), so the GUI re-implements that setup in a new `gui/backend.go`.
- **Must match the CLI exactly** so login is shared:
  - State dir: `$XDG_STATE_HOME/ipatool` or `$XDG_DATA_HOME/ipatool` if absolute, else `~/.ipatool` (constants.go: ConfigDirectoryName ".ipatool"), including the legacy-dir migration rules in prepareStateDirectory.
  - Cookie jar: `juju/persistent-cookiejar` file `<state>/cookies` (CookieJarFileName).
  - Keyring: `byteness/keyring` with AllowedBackends Keychain, SecretService, File; ServiceName "ipatool-auth.service"; FileDir = state dir; FilePasswordFunc returns the GUI's passphrase; wrapped with `keychain.New(keychain.Args{Keyring, Label: KeychainServiceName})`.
  - AppStore: `appstore.NewAppStore(appstore.Args{CookieJar, OperatingSystem, Keychain, Machine})` with `operatingsystem.New()` and `machine.New(machine.Args{OS: os})`. Args also has an optional `ActionSignerFactory`; leave it nil like the CLI does (default signer).
  - Opening the keyring: on Windows the CLI uses cmd/keyring_default.go (`//go:build !ios`), which is just `keyring.Open(config)`; the iOS variant doesn't apply.
- **Behaviour to port from cmd/** (read each file before porting): auth.go (login + 2FA: ErrAuthCodeRequired -> prompt -> retry with AuthCode), download.go (retry on ErrPasswordTokenExpired with re-login; on ErrLicenseRequired purchase if "free license" checked; then ReplicateSinf via replicateDownloadSinf rules), purchase, search, purchases (OwnedApps), list_versions, get_version_metadata.
- AppStore interface (pkg/appstore/appstore.go): Login, AccountInfo, Revoke, Lookup, Search, OwnedApps, Purchase, Download, ReplicateSinf, ListVersions, GetVersionMetadata, Bag.
- Progress: `DownloadInput.Progress` is a `*progressbar.ProgressBar`; create one with a custom writer (or io.Discard) and poll/hook its state to update a percentage in the GUI (status bar + an accessible progress/Result field). Cancel: `DownloadInput.Context` with a cancelable context.
- Work runs in goroutines; UI updates via `walk.App().Synchronize`. Keep the existing plain-language error mapping (friendlyError) but match on error values (errors.Is) where possible.
